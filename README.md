# Textile Inventory Tracker

A robust Store Inventory & Analytics Management system designed for textile retail environments, built using **C#** and **SQL Server**. This project optimizes daily store operations, streamlines inter-branch logistics, and provides managers with critical sales performance insights.

## 🚀 Key Features

### 🛒 Store Operations & Analytics
* **Product Performance Analytics:** Displays sales velocity and inventory trends using dynamic bar charts paired with granular data grids.
* **Inter-Store Stock Lookup:** Allows staff to instantly search item codes, view stock availability across other branches, check precise branch distance metrics ($km$), and route transfer requests.
* **Variant & Inventory Management:** Quick product search filtering by color variants and size/stock levels to assist customers on the fly.

### 📊 Planned Features (UI Mock-ups / Drafts)
To showcase full-system architecture and future scalability, the interface includes fully designed layouts for the following upcoming modules:
* **In-Store Locator Panel:** Designed for found/not-found logic validations to quickly direct staff to specific aisle locations (e.g., A5) and warehouse update logs.
* **HR & Staff Management:** Planned UI for querying employee profiles, updating internal roles, and monitoring shift activity logs.
* **Executive Document Generation:** Layouts for generating historical reports (daily, weekly, monthly) with format selections (Excel/PDF exports).
